# KrCustom 路由与页面规划

> 文档用途：前台、商家后台与管理员页面的路由地图。当前阶段仅做静态原型与模拟数据，不接入数据库。  
> 约定：正文用中文；所有用户可见页面名、按钮名、状态名同时给出自然韩文。

---

## 1. 用户角色

| 角色 | 韩文 | 说明 | MVP |
| --- | --- | --- | --- |
| 访客 | 비회원 / 방문자 | 可浏览首页、分类、搜索、服务详情、店铺；登录/注册前无订单与消息权限 | 是 |
| 普通用户 | 일반 회원 | 可聊天、下单、确认效果图与报价、寄送自带物品、查看订单与进度 | 是 |
| 商家 | 판매자 | 管理店铺、服务、订单、报价、效果图、自带物品、制作进度与物流 | 是（静态原型） |
| 平台管理员 | 플랫폼 관리자 | 平台治理、审核、纠纷与运营；**仅规划，不在 MVP 实现** | 否 |

## 2. 页面地图

│

│   ├── 서비스 /seller/services · new · [id]/edit
│   ├── 주문 /seller/orders · [id]

## 4. 前台页面说明

### 4.1 `/` 首页 / 홈

| 项 | 内容 |
| --- | --- |
| 页面目的 | 品牌入口与发现定制服务、商家、案例；引导发布需求与自带物品定制 |
| 主要用户 | 访客、普通用户 |
| 核心模块 | 顶部导航；搜索框；서비스 분류；인기 맞춤 서비스；추천 판매자；최근 사례；맞춤 요청 入口；내 물품 커스텀 入口 |
| 主要按钮 | 검색 / 검색；맞춤 요청하기；내 물품으로 커스텀；서비스 보기；상점 보기；더보기 |
| 必须展示 | 品牌名 커스텀코리아；分类入口；热门 Service 卡片（图、标题、最低价、商家）；推荐商家；案例缩略图；两个定制入口 |
| 跳转 | → `/search`、`/category/[slug]`、`/service/[id]`、`/store/[id]`、`/custom-request/new`、登录态下可 → `/messages`、`/orders` |
| MVP | 必须 |
| 移动端优先级 | P0 |
| 需登录 | 否 |
| 商家权限 | 否 |

**首页必含模块清单**

1. 顶部导航 / 상단 내비게이션  
2. 搜索框 / 검색창  
3. 服务分类 / 서비스 카테고리  
4. 热门定制服务 / 인기 맞춤 서비스  
5. 推荐商家 / 추천 판매자  
6. 最近案例 / 최근 사례  
7. 发布定制需求入口 / 맞춤 요청하기  
8. 用户自带物品定制入口 / 내 물품으로 커스텀

## 8. 核心用户流程

### 8.1 A. 固定价格直接购买 / 바로 구매

```text
홈·검색·카테고리 → 서비스 상세 → 옵션·파일 선택 → 장바구니/결제
→ 주문 생성 → 제작 → 배송 → 수령·리뷰
```

### 8.2 B. 沟通询价定制 / 견적 상담

```text
서비스 상세 → 채팅 상담 → 텍스트·이미지·파일·PSD
→ 시안 수신 → 시안 확인 → 견적서 수신 → 수락·결제
→ 제작 → 배송 → 수령·리뷰
```

### 8.3 C. 用户自带物品定制 / 내 물품 커스텀

```text
서비스 상세·入口 → 채팅·물품 사진 → 시안 확정 → 견적 확정·결제
→ 발송 정보 등록 → 판매자 수령·개봉 사진·물품번호·라벨
→ 제작·검수·완료 → 반송 배송 → 고객 수령 → 주문 완료
```

关键页面串联：`/messages/[id]` ↔ `/design-proofs/[id]` ↔ `/quotes/[id]` ↔ `/orders/[id]`（时间线）↔ `/seller/customer-items/[id]`
