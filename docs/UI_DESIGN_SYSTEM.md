# KrCustom UI 设计规范

> 项目：KrCustom｜品牌：커스텀코리아  
> 定位：面向韩国用户的综合定制服务交易平台  
> 文档语言：中文｜前台用户可见文案：自然韩文  
> 当前阶段：只建立规范，不安装字体/依赖，不改页面代码

**设计总方向**

- 信息效率参考 Temu、淘宝、Coupang：高密度、路径短、状态一目了然  
- 视觉更简洁、更现代：克制色、少阴影、少装饰  
- **不是**普通库存商品商城；核心实体是 Service  
- 必须突出：채팅、견적、시안 확인、고객 소지품 커스텀  
- 移动端优先，桌面端兼容  
- 金额 `15,000원`｜日期 `2026.07.12`｜手机 `010-1234-5678`

---

## 1. 设计原则

| 原则 | 说明 |
| --- | --- |
| 简单易懂 | 一屏一事；交易方式用标签直白标出，不依赖长文解释 |
| 交易状态清晰 | 订单/报价/效果图/物品状态用统一 StatusBadge，节点可追踪 |
| 定制流程可视化 | 用时间线、步骤条、聊天内卡片串联流程，禁止「黑盒进度条」了事 |
| 商家能力可信 | 评分、响应速度、认证、案例、累计订单可见，避免空泛口号 |
| 用户操作负担低 | 关键下一步永远可见；少填必填项；危险操作才二次确认 |
| 移动端优先 | 先定 375 布局，再扩展桌面；主 CTA 触达拇指区 |
| 高信息密度但不拥挤 |  tight spacing + 清晰分组；用分割与字重，而不是卡片套卡片 |
| 重要操作突出 | 채팅 문의、견적 요청 高于装饰与次要链接 |
| 风险提示明确 | 自带物品寄送、付款、取消、退款用 Warning/Danger 文案区 |
| 韩文阅读体验自然 | 避免生硬直译；标题宜短；长文断行友好；数字用韩元格式 |

**产品差异原则（相对普通电商）**

1. ServiceCard 必须露出交易方式，不能长得像库存 SKU 卡  
2. 服务详情操作区：询价/聊天不得弱于购买  
3. 聊天是交易主通道，不是客服附属窗  
4. 用户自带物品全流程必须可视化，不可弱化

### 2.2 视觉禁令

- 避免过度鲜艳的霓虹/荧光色  
- 避免大面积红色铺底（红仅用于危险与少量角标）  
- 避免复杂多层渐变背景  
- 避免多层大阴影与玻璃拟态堆叠  
- 避免过度圆角（胶囊满屏）  
- 避免花哨、无意义的入场动画  
- 避免紫色主题、厚重奶油纸感、暗黑默认皮肤（本品牌默认浅色）

## 3. 字体系统

当前阶段**不安装**字体依赖；实现可用系统字体栈。后续可接入 Pretendard，结构预留。

### 3.1 字体族

| 用途 | 推荐栈 | 说明 |
| --- | --- | --- |
| 韩文 | `"Pretendard", "Apple SD Gothic Neo", "Noto Sans KR", "Malgun Gothic", sans-serif` | Pretendard 为意图字体；未安装时回退系统韩文字体 |
| 英文 | 与韩文同一无衬线栈 | 避免混用衬线标题破坏密度感 |
| 数字/金额 | 同栈；金额可 `font-variant-numeric: tabular-nums` | 列表价格对齐 |

### 3.2 字号与字重

| 角色 | Token | 字号 | 行高 | 字重 | 场景 |
| --- | --- | --- | --- | --- | --- |
| 页面大标题 | `text.display` | 28px / 24px 移动 | 1.3 | 700 | 홈 히어로 외 少用 |
| 区块标题 | `text.h1` | 22px | 1.35 | 700 | 페이지 제목 |
| 卡片/模块标题 | `text.h2` | 18px | 1.4 | 600 | 서비스명、상점명 |
| 小标题 | `text.h3` | 16px | 1.4 | 600 | 섹션 소제목 |
| 正文 | `text.body` | 15px | 1.55 | 400 | 설명、채팅 본문 |
| 辅助文字 | `text.caption` | 13px | 1.45 | 400 | meta、시간、도움말 |
| 微标签 | `text.micro` | 12px | 1.35 | 500 | 배지、태그 |
| 按钮文字 | `text.button` | 15px | 1 | 600 | 버튼 |
| 按钮小 | `text.buttonSm` | 13px | 1 | 600 | 칩/小按钮 |
| 金额强调 | `text.price` | 16–20px | 1.2 | 700 | 최저가、견적 합계 |

**韩文行高**：正文不低于 1.5；多行说明允许 1.6。标题不超过 2 行省略。

## 4. 页面布局

| 项 | 规范 |
| --- | --- |
| 桌面端最大内容宽度 | `1200px`（商家后台内容区 `1280px` 含侧栏内边距） |
| 桌面端左右边距 | 内容区相对视口不足最大宽时：`24px`；≥1440 时可 `32px` |
| 平板端（768–1023） | 内容满宽，左右 `20px`；双列卡片 |
| 移动端安全边距 | 左右 `16px`；底部需避开底栏与 Home Indicator：内容底 `16px + bottomNav` |
| Grid | 12 列桌面；槽宽 `16px`；移动端实质 4 列逻辑 |
| 卡片间距 | 列表网格 `gap: 12px`（移动）/ `16px`（桌面） |
| 区块间距 | 模块之间 `24px`（移动）/ `32px`（桌面） |
| 顶部导航高度 | 桌面 `64px`；移动 `56px` |
| 移动端底部导航高度 | `56px` + `env(safe-area-inset-bottom)` |
| 商家后台侧边栏宽度 | 展开 `240px`；折叠 `64px`（仅图标，平板可默认折叠） |

**服务详情桌面**：左媒体 `7` / 右信息与 CTA `5`。  
**聊天桌面**：可左会话列表 `360px` + 右聊天；移动为全屏子页。

## 6. 按钮体系

### 6.1 基础类型

| 类型 | 外观 | 用途 |
| --- | --- | --- |
| Primary | 底 `#0F766E`，字白 | 当前场景最关键正向动作 |
| Secondary | 底 `#F0F9FF` 或浅品牌底，字 `#0369A1` / `#0F766E` | 并行重要动作（如与 Primary 并列的询价） |
| Outline | 白底，边框 `#CBD5E1`，字主色 | 次要、取消、返回 |
| Ghost | 无边框，字 `#0F766E` 或主文字 | 三级文字按钮、表格行内 |
| Danger | 底 `#DC2626`，字白 | 删除、取消订单、确认退款 |
| Icon Button | 40×40（移动最小点击 44×44），圆角 `8px` | 附件、更多、扫码入口 |
| Full-width Mobile | 宽 100%，高 `48px` | 移动表单提交 |
| Sticky Bottom Action | 固定底栏，内边距 `12px 16px`，上描边，可双按钮并排 | 상세页/确认页主操作 |

**尺寸**：高 `40px` 默认、`48px` 强调、`32px` 紧凑。内边距水平 `16px`。

### 6.2 前台关键按钮优先级

| 韩文按钮 | 建议样式 | 优先级说明 |
| --- | --- | --- |
| 채팅 문의 | Primary 或与견적并排的强调 Secondary（描边品牌色加粗） | **必须非常显眼**；详情页首屏可见 |
| 견적 요청 | Primary / 强 Secondary | **必须非常显眼**；不得做成灰色文字链接 |
| 바로 구매 | Outline 或 Secondary | **不能始终压过询价**；仅纯固定价服务可升为 Primary |
| 시안 확인 | Primary | 效果图页主操作 |
| 결제하기 | Primary | 报价确认/结算 |
| 물품 발송 등록 | Primary（用户侧待办时） | 时间线「等待寄件」时置顶 |
| 수령 확인 | Primary（商家） | 自带物品收货 |
| 제작 시작 | Primary | 收货完成之后 |
| 제작 완료 | Primary | 制作流终点确认 |
| 반송 등록 | Secondary / Primary | 完工后主路径 |

同一屏超过两个实心 Primary 时：只保留一个 Primary，其余改 Secondary/Outline。

**危险操作**：取消、删除、退款必须二次确认弹窗；主按钮用 Danger；默认焦点在取消上。

## 7. 输入组件

### 7.1 组件清单

| 组件 | 要点 |
| --- | --- |
| 文本输入框 | 高 44px（移动友好）；左右 `12px` |
| 搜索框 | 左搜索图标；右清除；圆角 `8px`；首页可略高 `48px` |
| 텍스트域 | 最小 3 行；可拖高；用于需求、시안 의견 |
| Select | 原生或自定义均需清晰 chevron；移动端优先系统 picker |
| Checkbox / Radio | 选中色品牌主色；标签可点 |
| 数量选择器 | − / 数值 / +；最小值尊重起订量 |
| 价格输入 | 右对齐；后缀 `원`；千分位 |
| 文件上传 | 虚线框 +「파일 첨부」；显示名/大小 |
| 图片上传 | 网格缩略图 + 删除；多图上限文案 |
| PSD 文件上传 | 独立类型标识「PSD」；显示文件名与大小；**不做在线预览**（MVP） |
| 日期选择 | 展示 `YYYY.MM.DD` |
| 地址输入 | 分区邮编/地址/详细；韩国址习惯 |
| 物流单号输入 | 等宽数字友好；택배사 Select 配套 |
| 手机号输入 | 展示/格式化为 `010-1234-5678` |

### 7.2 状态

| 状态 | 表现 |
| --- | --- |
| 默认 | 白底，边框 `#E2E8F0` |
| Focus | 边框 `#0F766E`，外环 `0 0 0 3px rgba(15,118,110,0.15)` |
| Error | 边框 `#DC2626`，下方错误文案红色 caption |
| Disabled | 底 `#F1F5F9`，字 `#94A3B8`，不可聚焦操作 |

**帮助文字**：输入框下方灰色 caption（例：`주문번호와 함께 동봉해 주세요.`）  
**错误提示**：字段级优先；表单提交可顶部汇总。勿只用变红边框而无文字。

## 8. 卡片组件

### 8.1 ServiceCard

| 元素 | 说明 |
| --- | --- |
| 图片 | 4:3 或 1:1；圆角随卡 |
| 服务标题 | 最多 2 行 |
| 店铺名称 | caption，可点进店铺 |
| 最低价格 | `15,000원~`，字重 700 |
| 评分 | 星 + 分（例 `4.8`） |
| 支持的交易方式 | 小标签：즉시구매 / 견적 / 소지품 |
| 制作周期 | 例 `3~5일` |
| 标签 | 급행、인증 등 |

禁止：仅大图+价，看不出是定制 Service。

### 8.2 StoreCard

店铺 Logo、店铺名称、评分、응답속도（例 `평균 12분`）、누적 주문、인증状态、主要服务类别。

### 8.3 QuoteCard

报价编号、商家、服务、总金额、有效期、当前状态、버튼 `상세 보기`。状态用 StatusBadge。

### 8.4 DesignProofCard

版本号（`v2`）、缩略图、商家说明、用户确认状态、按钮 `시안 확정` / `수정 요청`。

### 8.5 CustomerOwnedItemCard

物品编号、物品图片、用户姓名、手机号后四位（`****5678`）、订单号、当前物品状态、`수령 확인`、`라벨 인쇄`。

### 8.6 OrderCard

订单号、服务名称、商家、金额、订单类型（바로구매 / 견적 / 소지품）、当前状态、**关键下一步**文案按钮（例：`시안 확인하기`、`발송 정보 등록`）。

## 10. 聊天界面规范

### 10.1 支持的消息类型

文字、이미지、파일、PSD、서비스 카드、시안 카드、견적 카드、주문 카드、배송 카드、시스템 메시지。

### 10.2 样式规则

| 项 | 规范 |
| --- | --- |
| 用户消息 | 右对齐；气泡底 `#0F766E`；字白；圆角 `12px`（右下略小） |
| 商家消息 | 左对齐；白底边框；主文字色 |
| 系统消息 | 居中；灰底胶囊或纯 caption；不可点除非含链接 |
| 时间显示 | `오후 2:30` 或 `2026.07.12 14:30`；消息组间距合并时间 |
| 已读状态 | 用户消息下方小字 `읽음`（静态原型可模拟） |
| 未读提示 | 会话列表红点/数字；聊天顶栏可略 |
| 文件大小 | 名下 caption：`2.4MB` |
| 图片预览 | 气泡内最大宽 70% 屏宽；点击可大图（MVP 可占位） |
| 报价卡片操作 | 内嵌金额 + `견적서 보기` / `수락 및 결제` |
| 效果图确认操作 | 缩略图 + `시안 확인하기` |
| 移动端输入区 | 底栏固定：附件、输入、发送；高约 `56px`+safe；附件菜单含 이미지/파일/PSD |

**商业卡片消息**（服务/报价/效果图/订单/物流）：白底、左边品牌色 `3px` 条、内边距 `12px`，操作按钮不低于 36px 高。

## 14. 响应式规则

| 断点 | 范围 | 要点 |

| 场景 | 规则 |

## 15. 无障碍与易用性

- **对比度**：正文与背景对比 ≥ 4.5:1；主按钮白字于品牌色满足 AA  
- **键盘操作**：可 Tab 到全部可操作控件；弹窗内焦点陷阱  
- **Focus 可见**：不得 `outline: none` 无替代；使用品牌色 focus ring  
- **图片 Alt**：服务图、效果图、开箱图需有意义 alt（韩文）  
- **表单 Label**：每个输入有可见 label 或 `aria-label`  
- **错误提示**：与字段 `aria-describedby` 关联  
- **点击区域**：不小于 44×44px  
- **颜色不是唯一状态**：徽章必有文字；时间线必有文案节点  
- **韩文长文本**：`word-break: keep-all` 优先；必要时 `overflow-wrap`  
- **老年用户可读性**：正文 ≥15px；关键状态勿用过浅灰；避免仅靠细线区分

## 17. 禁止事项

1. 不允许前台显示中文  
2. 不允许在组件里散落大量韩文硬编码（集中到语言文件）  
3. 不允许同一种按钮在不同页面使用完全不同样式  
4. 不允许把询价入口弱化成次要文字链接  
5. 不允许用颜色作为唯一状态标识  
6. 不允许移动端出现横向溢出  
7. 不允许用过多动画影响操作  
8. 不允许使用无法解释的随机颜色（必须来自本色板 Token）  
9. 不允许把 ServiceCard 设计成普通库存商品卡片  
10. 不允许弱化用户自带物品流程
